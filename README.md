# Real Estate What‑If Market Analyzer

This project is developed as part of the **BITS Pilani WILP – BSc Design and Computing** program.

## 📌 Objective
An interactive dashboard that allows users to analyze housing trends and predict property prices using a What‑If calculator.

## 🛠 Tools Used
- Python
- Pandas
- scikit-learn
- Streamlit

## 🚀 Features
- Multiple Linear Regression price prediction
- Interactive sliders for house features
- Visual market analysis charts

## 📂 Dataset
Public housing dataset adapted for academic use.

## ✅ Deployment
Deployed using **Streamlit Cloud** connected to GitHub.
